# Definition of Done (DoD)

A user story is only considered **"Done"** when ALL of the following are true:

1. **Code is written** and follows the team's agreed coding style.
2. **Code compiles** with no errors under JDK 21.
3. **Acceptance criteria pass** — every Given-When-Then scenario for the
   story has been manually or automatically verified.
4. **Unit tests** exist for the new code and all tests pass.
5. **Code has been reviewed** by at least one other team member (or, for
   individual submission, self-reviewed against this checklist).
6. **Documentation updated** — `backlog.md`, `traceability-matrix.md`, and
   `SRS.md` reflect the change if it affects requirements.
7. **No known critical bugs** remain open for the story.
8. **Committed and pushed to GitHub** with a clear, descriptive commit
   message referencing the story ID (e.g. `git commit -m "US-01: add sales rep login"`).
9. **Moved to "Done" column** on the GitHub Projects board.
