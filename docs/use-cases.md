# Use Cases — Sales Management System

This document provides the supporting use-case references for the backlog.

## UC-01 Sales Rep Authentication
A salesperson enters their system ID and password to access the sales dashboard.

## UC-02 View Sales Pipeline
A salesperson views active leads and opportunities with values and status.

## UC-03 Download Sales Report
A salesperson downloads a PDF sales report after a period of activity.

## UC-04 Toggle Theme
A user switches between light and dark mode to improve comfort.

## UC-05 SMS Follow-Up Reminder
A salesperson receives an SMS reminder when a follow-up meeting is approaching.
